# Piyare Mobile Telecom v5.1 Production Package

Owner-first multipage website + Google Sheets/Drive backend.

### Production features
- Owner Control Room with session login
- Server-side role-based authorization
- Owner / Manager / Editor / Support roles
- Website content editor
- Homepage block manager
- Banner upload to Drive
- Products / Orders / Repairs / Coupons modules
- Customer reviews and feedback
- Analytics
- Low-stock alerts
- Notification center
- Backup + verified restore
- Audit/activity log
- SEO manager structure
- Contact + repair tracking
- No dedicated database required

### Storage
Google Sheets = structured business data.
Google Drive = public website media + private backups.

See `PRODUCTION_SETUP.md` for deployment.
